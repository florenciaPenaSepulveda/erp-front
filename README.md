# erp-front

Frontend del ERP (React + TypeScript + Vite). Base: ERPFront de javierm-0, para continuar su mejora.

## Tecnologías

- React
- Vite
- TypeScript

## Estructura

```
📄 README.md
📄 eslint.config.js
📄 index.html
📄 package-lock.json
📄 package.json
📁 public
📁 src
📄 tsconfig.app.json
📄 tsconfig.json
📄 tsconfig.node.json
📄 vite.config.ts
```

## Cómo ejecutarlo

```bash
npm install
npm run dev
npm run build
```
